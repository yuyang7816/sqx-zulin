# 用户端运行教程

这份教程教你如何在本机跑起 **用户端（C 端）**，文件夹 **`zulinshangcheng-uniapp`**。  
应用名称：**租赁商城**。底部导航：**首页、分类、订单、我的**。

**必须先启动服务端。** 见 [服务端运行教程](服务端-运行教程.md)。  
管理端是否启动不影响用户端打开首页，但**没有商品数据、无法登录管理端配的商品**时，列表可能为空。

---

## 用户端是什么

用户端是租赁客户在 **手机微信 / 浏览器 H5 / App** 里用的界面。你自己不直接改数据库；所有数据来自 **服务端接口**。

- 代码目录：`zulinshangcheng-uniapp`
- 推荐开发工具：**HBuilderX**（也支持 CLI，但 HBuilderX 最省事）
- 线上 H5 演示（与仓库同源）：https://leaseshopyh.xianmxkj.com

---

## 开始之前要准备什么

| 准备项 | 说明 |
|---|---|
| 已启动的本机服务端 | `http://127.0.0.1:9101/sqx_fast/swagger-ui.html` 能打开 |
| HBuilderX | https://www.dcloud.io/hbuilderx.html 下载正式版 |
| Chrome 浏览器 | 用于「运行到浏览器」 |
| （可选）微信开发者工具 | 运行微信小程序时要装 |

---

## 第 1 步：改接口地址（本地联调必做）

用 VS Code 或记事本打开：

**`zulinshangcheng-uniapp/common/config.js`**

**本地联调**时改成（注意：**http**、端口 **9101**、后缀 **`/sqx_fast`**）：

```javascript
const ROOTPATH = "http://127.0.0.1:9101/sqx_fast";
const ROOTPATH1 = "http://127.0.0.1:9101/sqx_fast";
const ROOTPATH2 = "ws://127.0.0.1:9101/sqx_fast/websocket/"; // 联系客服（WebSocket）
const ROOTPATH3 = "ws://127.0.0.1:9101/wss/chatSocket/"; // 聊天（若你环境路径不同，以实际部署为准）
const ROOTPATH4 = "http://127.0.0.1:9101/sqx_fast";

module.exports = {
	APIHOST: ROOTPATH,
	APIHOST1: ROOTPATH1,
	WSHOST: ROOTPATH2,
	WSHOST1: ROOTPATH3
};
```

仓库默认可能是线上 `https://leaseshopyh.xianmxkj.com/...`，**本地跑必须改成 127.0.0.1**，否则会连到别人服务器的数据。

线上演示时保持默认域名即可；`ROOTPATH4` 多用于分享链接域名，可与 `ROOTPATH` 保持一致。

改完点 **保存**。

---

## 第 2 步：安装 npm 依赖（样式异常时必做）

部分组件（如 **uView UI**）需要 `node_modules`。在 `zulinshangcheng-uniapp` 目录打开终端：

```bash
cd zulinshangcheng-uniapp
npm install
```

若从未装过 Node，请先安装 Node.js（14+ 即可）。只需在**第一次打开项目**或**依赖报错**时执行。

---

## 第 3 步：用 HBuilderX 打开正确目录

1. 打开 HBuilderX。
2. 菜单 **文件 → 打开目录**。
3. 选中 **`zulinshangcheng-uniapp` 文件夹本身**。  
   ❌ 不要选上一级项目根目录（那一层还有 `zulinshangcheng-server`、`zulinshangcheng-admin`，选错会编译失败）。

左侧项目树顶层应显示 `zulinshangcheng-uniapp`。

---

## 第 4 步：运行到浏览器（H5）

1. 菜单 **运行 → 运行到浏览器 → Chrome**（或内置浏览器）。
2. 第一次会下载编译插件，请等待控制台滚动结束。
3. 浏览器自动打开，地址类似 `http://localhost:8080` 或 HBuilder 分配的端口。
4. 应看到 **「租赁商城」** 首页和底部 **首页 / 分类 / 订单 / 我的**。

### 怎样算 H5 联调成功

1. 首页有分类入口、搜索框、热租商品等区域。
2. 点 **我的**，未登录时显示 **「点击登录」** 或跳转登录页。
3. 按键盘 **F12** → **网络（Network）** → 刷新页面：接口应请求 **`127.0.0.1:9101/sqx_fast`**（若仍出现 `leaseshopyh.xianmxkj.com`，说明第 1 步没保存或没重新运行）。

---

## 第 5 步：登录演示

在「我的」→ 登录，可使用：

- **手机号 + 密码**
- **手机号 + 短信验证码**（需后台开通短信；测试环境可在管理端配置**模拟验证码**）

**本机数据库**若没有测试用户，请先在用户端 **注册**，或在管理端查看用户列表。

线上 H5 可直接打开：https://leaseshopyh.xianmxkj.com ，体验完整演示数据（与线上一致，账号以线上库为准）。

登录前须勾选 **《用户协议》《隐私政策》**。

---

## 第 6 步（可选）：运行到微信小程序

1. 安装 [微信开发者工具](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)。
2. HBuilderX：**运行 → 运行到小程序模拟器 → 微信开发者工具**。
3. 首次要在 `manifest.json` → 微信小程序里填写自己的 **AppId**（测试号亦可，真机预览需正式小程序）。
4. 微信开发者工具里打开项目后，同样依赖 `config.js` 里的接口地址。

未配置微信时，微信登录按钮会提示未开通；**手机号密码 / 验证码登录**不受影响。

## 常见问题

**打开的是空白页 / 报错 uView**  
确认打开目录是 `zulinshangcheng-uniapp`，并在该目录执行过 `npm install`。

**列表一直「暂无数据」**  
服务端未启动；或 `config.js` 仍指向线上而线上没权限；或本机未导入 `lease-shop.sql`（需在管理端发布商品）。

**登录提示网络错误**  
检查服务端窗口是否还在、端口是否为 9101、`config.js` 是否写错 `https` / 漏写 `/sqx_fast`。

**H5 能开，但聊天 / 客服连不上**  
`WSHOST` / `WSHOST1` 要与服务端实际 WebSocket 路径一致；本地一般用 `ws://127.0.0.1:9101/...` 联调。

**改完 config 没生效**  
HBuilderX 菜单 **运行 → 停止**，再重新「运行到浏览器」。

**和本机管理端数据不一致**  
确认服务端 `application-dev.yml` 连的是本机已导入 `lease-shop.sql` 的库，且用户端 `config.js` 指向本机 9101，而不是线上域名。

各页面能点什么，见 [用户端功能说明](用户端-功能说明.md)。
