# 服务端运行教程

请**按顺序**做。做完一步，先看到文中写的「成功标志」，再做下一步。**不要跳步。**

## 服务端是什么

整套租赁商城系统里，有两个给你「点界面」的部分：**管理端**（电脑后台）和**用户端**（手机 H5 / 微信小程序 / App）。除此以外，还要先跑起来一个**看不见网页的后台程序**，就叫**服务端**。

可以把它理解成「总台」：

- 管理端和用户端**自己不会改数据库**。
- 它们把「登录、查商品、下单、付钱、上传图片、申请提现」等请求发给服务端。
- 服务端检查是否允许，把结果存进 **MySQL 数据库**；需要发短信、收微信付款、把图片存到网上时，再去访问外部的短信、支付、云存储等服务。

代码在文件夹：**`zulinshangcheng-server`**（里面是 Maven 多模块 Java 工程）。

服务端**没启动**时，管理端和用户端有时能打开页面，但**登录会失败**、验证码图片会裂开、商品列表可能是空的。

## 开始之前要准备什么

在自己的电脑上安装下面软件。安装时尽量勾选「添加到 PATH」或「Add to PATH」。

| 软件 | 用什么版本 | 怎样确认已经装好 |
|---|---|---|
| **JDK** | **1.8**（也叫 Java 8） | 打开终端，输入 `java -version`，能看到 `1.8.0_xxx` |
| **Maven** | 3.8 或更高 | 输入 `mvn -v`，能看到 `Apache Maven 3` 且 Java 版本是 1.8 |
| **MySQL** | 8.0（5.7 一般也可） | 能连上本机 MySQL，端口一般是 **3306** |

### 怎样打开终端（Windows）

按键盘 `Win + R`，输入 `powershell`，回车。或开始菜单搜索「PowerShell」。

### Java 怎么装

**不要用 Java 11、17、21 直接替换本项目。** 仓库按 **Java 8** 编译。可用 Adoptium Temurin 8：  
https://adoptium.net/temurin/releases/?version=8

装好后**关掉原来的终端，再开一个新的**，输入 `java -version` 确认。

### Maven 怎么装

下载：https://maven.apache.org/download.cgi  
解压后把 `bin` 目录加到系统 PATH，再新开终端执行 `mvn -v`。

### MySQL 怎么装

安装时会给 `root` 设密码、确认端口（一般 3306）。**把密码记下来**，后面改配置文件要用。

不会命令行可以用 **Navicat**、**MySQL Workbench** 等图形工具连库。

### Redis 要不要装

`application.yml` 里默认 `spring.redis.open: false`，**第一次跑起来可以不装 Redis**。以后若在配置里打开 Redis，再安装并把地址写进 yml。

### 数据库脚本说明

业务数据在 MySQL 里。本仓库脚本位置：

**`zulinshangcheng-server/sql/lease-shop.sql`**

先建库再导入这份文件。未导入时：服务端也许能启动，但**无法登录管理端、商品列表为空**。

## 第 1 步：新建空数据库

脚本一般会建表和数据，但**不会自动创建库名**。要先建库。

库名请与后面 `application-dev.yml` 里 JDBC 地址一致。脚本配套库名为 **`lease-shop`**，本文示例建库也用 **`lease-shop`**（若你坚持用其它名字，建库、导入、yml 三处须一致）。

### 方法 A：命令行

```bash
mysql -uroot -p你的密码
```

在 MySQL 里执行：

```sql
CREATE DATABASE IF NOT EXISTS `lease-shop` DEFAULT CHARACTER SET utf8mb4 COLLATE utf8mb4_general_ci;
SHOW DATABASES;
```

列表里有 `lease-shop` 即可。输入 `exit` 退出。

### 方法 B：Navicat

1. 连接本机 MySQL（主机 `127.0.0.1`，端口 `3306`，用户 `root`，密码为你设的密码）。
2. 右键 →「新建数据库」。
3. 名称填 `lease-shop`，字符集 `utf8mb4`，排序规则 `utf8mb4_general_ci`。

---

## 第 2 步：导入数据库脚本

将仓库里的脚本导入到第 1 步建的库：

**文件路径（相对项目根目录）：`zulinshangcheng-server/sql/lease-shop.sql`**

**不要导入到别的业务库**，脚本里含 `DROP TABLE`，会覆盖同名表。

### 命令行示例

先 `cd` 到**整个项目根目录**（能看到 `zulinshangcheng-server`、`zulinshangcheng-admin` 文件夹）。

**Windows PowerShell：**

```powershell
$mysql = "C:\Program Files\MySQL\MySQL Server 8.0\bin\mysql.exe"
& $mysql -uroot -p你的密码 -P3306 --default-character-set=utf8mb4 "lease-shop" -e "source $($PWD.Path -replace '\\','/')/zulinshangcheng-server/sql/lease-shop.sql"
```

**macOS / Linux：**

```bash
mysql -uroot -p你的密码 -P3306 --default-character-set=utf8mb4 lease-shop < zulinshangcheng-server/sql/lease-shop.sql
```

### Navicat

1. 双击打开 `lease-shop` 库。  
2. 「运行 SQL 文件」→ 选中项目里的 **`zulinshangcheng-server/sql/lease-shop.sql`**。  
3. 编码 **UTF-8** → 执行，无红色报错即成功。

导入成功后，管理端默认账号一般在脚本里，常见为：

| 项目 | 值 |
|---|---|
| 用户名 | `admin` |
| 密码 | `123456` |

## 第 3 步：让服务端连接你的 MySQL

1. 用记事本或 VS Code 打开：

   `zulinshangcheng-server/sqx-admin/src/main/resources/application.yml`

   确认环境为开发配置（仓库默认多为）：

   ```yaml
   spring:
     profiles:
       active: dev
   ```

2. 打开同目录下的 **`application-dev.yml`**，找到 `spring.datasource.druid`，改成你的 MySQL：

   ```yaml
   url: jdbc:mysql://127.0.0.1:3306/lease-shop?useUnicode=true&characterEncoding=utf-8&useSSL=false
   username: root
   password: 你的密码
   ```

   - 端口不是 3306 时，改 URL 里的端口号。
   - **库名**必须与第 1 步一致（如 `lease-shop`）。
   - 保存文件。

> 注意：仓库里的 `application-dev.yml` 有时会带演示用账号密码。本地联调务必改成**你自己的 MySQL 密码**，并确认连的是**本机 `127.0.0.1`**，不要用别人的远程数据库。

---

## 第 4 步：启动服务端

任选一种方式。**启动窗口要一直开着**，关掉就等于停服。

### 方法 A：命令行（Maven）

1. 终端进入 `zulinshangcheng-server` 文件夹，例如：

   ```powershell
   cd "D:\开源文件整理\开源-三端\租赁三端开源\zulinshangcheng-server"
   ```

   （请改成你电脑上**真实的项目路径**。）

2. 第一次编译并运行（会下载依赖，可能 **10～30 分钟**）：

   ```bash
   mvn clean install -DskipTests
   cd sqx-admin
   mvn spring-boot:run
   ```

### 方法 B：IntelliJ IDEA

1. 用 IDEA 打开 **`zulinshangcheng-server`**（选带根 `pom.xml` 的那一层）。
2. 等 Maven 导入结束，Project SDK 选 **1.8**。
3. 安装 **Lombok** 插件并开启注解处理（若提示缺少 Lombok）。
4. 打开 `sqx-admin/src/main/java/com/sqx/SqxAdminApplication.java`，点绿色运行。
5. Active profiles 填 **`dev`**（若运行配置里可填）。

**成功标志：** 控制台出现 **`租赁商城启动成功`**，并有 Spring Boot 的 `Started SqxAdminApplication` 字样。

## 怎样算成功

用 Chrome 或 Edge 打开：

**http://127.0.0.1:9101/sqx_fast/swagger-ui.html**

能看到 **Swagger** 接口文档页面，说明服务端已在监听。

| 项目 | 值 |
|---|---|
| 端口 | **9101**（以 `application.yml` 的 `server.port` 为准） |
| 接口前缀 | `/sqx_fast` |
| 接口文档 | `http://127.0.0.1:9101/sqx_fast/swagger-ui.html` |
| 图片上传（匿名） | `POST /sqx_fast/alioss/upload`，表单字段名 `file` |

接下来请按 [管理端运行教程](管理端-运行教程.md) 启动后台，再按 [用户端运行教程](用户端-运行教程.md) 启动手机端。

微信、支付宝、短信、OSS 等要在管理端「配置列表 / 商城配置」里填密钥；没填时，界面能开，但真正发短信、收款会失败。说明见 [服务端功能说明](服务端-功能说明.md)。

## 常见问题

**`java` 不是内部或外部命令，或版本不是 1.8**  
未安装 JDK 8 或未加入 PATH。安装 Temurin 8 后**重新开终端**。

**`mvn` 不是内部或外部命令**  
Maven 的 `bin` 未加入 PATH。

**`Access denied for user 'root'`**  
yml 里的 MySQL 密码与真实密码不一致。

**`Communications link failure`**  
MySQL 服务没开，或 URL 主机 / 端口错误。

**`Unknown database 'lease-shop'`（或其它库名）**  
第 1 步建库失败，或 yml 里 URL 库名与建库名不一致。

**导入 SQL 中文乱码**  
命令行加 `--default-character-set=utf8mb4`；Navicat 选 UTF-8。

**`Port 9101 was already in use`**  
关掉旧的服务端 Java 进程后再启动。

**启动报 Redis 错**  
若你打开了 `spring.redis.open`，需先启动 Redis 并对齐配置；否则保持 `false` 关闭即可。

**管理端验证码图片裂开**  
服务端没启动，或管理端代理没有指向本机 `http://127.0.0.1:9101/sqx_fast`。

**控制台一直下载依赖**  
首次需从网络拉 jar 包，请耐心等待；可配置 Maven 阿里云镜像加速。
