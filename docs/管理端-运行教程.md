# 管理端运行教程

这份教程面向**不会写代码**的人。请按顺序做。

管理端是**电脑浏览器里打开的网站**，不是手机 App。工作人员用它维护商品、订单、会员和系统参数。登录页品牌名是 **「省钱兄设备租赁系统」**。代码文件夹：**`zulinshangcheng-admin`**。

**必须先启动服务端。** 请完整做完 [服务端运行教程](服务端-运行教程.md)。服务端控制台里要已经出现 **「租赁商城启动成功」**，并且**不要关闭**那个窗口。

服务端没开时：管理端页面也许能打开，但**验证码图片是裂的**，点登录会失败。

---

## 开始之前要准备什么

| 准备项 | 说明 |
|---|---|
| **Node.js** | 建议 **14 或以上**（能跑 Webpack 即可）。下载：https://nodejs.org/ 安装时勾选 **Add to PATH**。 |
| **浏览器** | Chrome 或 Edge（最新版）。 |
| **已启动的服务端** | 本机 `http://127.0.0.1:9101/sqx_fast/swagger-ui.html` 能打开。 |

安装 Node 后，**关闭旧终端，新开 PowerShell**，输入：

```bash
node -v
npm -v
```

应能看到 Node 与 npm 的版本号。

---

## 第 1 步：把管理端指向本机服务端

管理端在开发模式下，会通过 **Webpack 代理** 把 `/sqx_fast` 开头的请求转发到服务端。配置文件在：

**`zulinshangcheng-admin/config/index.js`**

用记事本或 VS Code 打开，找到 `proxyTable` 里的 `target`，改成本机（注意端口 **9101** 和路径 **`/sqx_fast`**）：

```javascript
proxyTable: {
  '/sqx_fast': {
    target: 'http://127.0.0.1:9101/sqx_fast',
    // target: 'https://leaseshopadmin.xianmxkj.com/sqx_fast',
    changeOrigin: true,
    pathRewrite: {
      '^/sqx_fast': ''
    }
  },
  // ...
}
```

**保存文件。**

> 说明：仓库默认 `target` 可能指向线上演示站。本地联调时务必改成 **`127.0.0.1:9101`**，否则会连到别人的数据库。

### 上传图片时也要注意

管理端很多页面的图片上传走：

`POST /sqx_fast/alioss/upload`

开发时请求会经代理打到本机服务端。若上传失败，请确认：

1. 服务端已启动；
2. 第 1 步代理已指向本机；
3. 浏览器 F12 →「网络」，看重定向到的地址是否是 `127.0.0.1:9101`。

---

## 第 2 步：安装依赖（只需在首次或依赖变更时）

1. 打开 PowerShell，`cd` 到 `zulinshangcheng-admin`。示例：

   ```powershell
   cd "D:\开源文件整理\开源-三端\租赁三端开源\zulinshangcheng-admin"
   ```

2. 执行：

   ```bash
   npm install
   ```

   会在本机生成 `node_modules` 文件夹（体积较大）。第一次可能需几分钟。

---

## 第 3 步：启动开发网站

仍在 `zulinshangcheng-admin` 目录执行：

```bash
npm run dev
```

终端里出现类似 **`Your application is running here: http://localhost:8009`**（端口以实际输出为准，默认 **8009**，被占用时会自动换端口）即表示已启动。

**这个终端窗口也要一直开着。** 按 `Ctrl + C` 会停止网站。

---

## 第 4 步：登录后台

1. 浏览器打开上一步提示的地址，一般是：**http://127.0.0.1:8009** 或 **http://localhost:8009**
2. 应看到 **「省钱兄设备租赁系统」** 登录页和账号、密码、验证码输入框。
3. 验证码图片应能正常显示（右侧有一张小图）。看不清就**点图片换一张**。
4. 输入（以你导入的数据库为准，常见演示账号）：

   | 项目 | 值 |
   |---|---|
   | 用户名 | `admin` |
   | 密码 | `123456` |
   | 验证码 | 看图输入 |

5. 点「登录」。成功后会进入带**左侧菜单**的主界面。

---

## 怎样算成功

- 验证码不是裂图。
- 左侧能看到「商品管理」「订单中心」「用户列表」等（具体以你的角色权限为准）。
- 按 `F12` →「网络 / Network」→ 再点一个菜单：请求 URL 应以 **`127.0.0.1:9101/sqx_fast`** 或经本地代理转发，而不是只访问远程线上域名。

接下来请按 [用户端运行教程](用户端-运行教程.md) 启动用户端。

各菜单能做什么，见 [管理端功能说明](管理端-功能说明.md)。

## 常见问题

**验证码一直是裂图**  
服务端没启动；或 `config/index.js` 代理未指向本机；或本机防火墙拦截了 9101 端口。

**提示用户名或密码错误**  
数据库未导入，或不是默认 `admin` / `123456`。用 Navicat 查 `admin_info` 等管理员表，或重新导入 `lease-shop.sql`。

**`npm install` 报错**  
可尝试换 Node 14～18 LTS；删除 `node_modules` 后重新 `npm install`（保留 `npm-shrinkwrap.json`）。

**改完代理配置仍访问线上**  
必须 `Ctrl+C` 停掉 `npm run dev`，再执行一次 `npm run dev`。

**登录成功但左侧没有菜单**  
当前管理员角色未分配菜单权限；在库里检查 `sys_menu` / 角色关联，或用超级管理员账号。

**上传图片失败**  
确认服务端 `/alioss/upload` 可用；管理端是否走了本机代理；管理端「配置列表」里文件存储方式是否可联调。

**页面能开但所有列表为空**  
服务端连的数据库是空的，或 `application-dev.yml` 仍指向远程库；请导入 `lease-shop.sql` 并改成本机库。
