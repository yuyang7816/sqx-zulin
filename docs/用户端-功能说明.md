# 用户端功能说明

用户端是 **租赁客户（C 端）** 在 **手机或电脑浏览器** 里打开的应用。应用名：**租赁商城**（全局标题亦可显示「码兄租赁商城」）。底部固定四个入口：**首页、分类、订单、我的**。

这份说明按「打开后能点到什么、会连带什么服务」来写。  
怎么启动见 [用户端运行教程](用户端-运行教程.md)。

---

## 这个端是给谁用的

- **租赁用户**：浏览商品 → 选租期下单 → 收货使用 → 归还 → 评价 / 投诉 / 开票。
- **不用这个端的人**：平台员工（**管理端**在电脑上操作发货、审核、配置）。

---

## 登录、注册、找回密码

路径一般在 **`我的` → 点击登录** 或 **`pages/public/login`**。

### 登录方式

1. **欢迎页**：品牌「码兄租赁」，宣传数码设备灵活租用。
2. **手机号 + 密码**：输入 11 位手机号和密码，勾选 **《用户协议》《隐私政策》** 后登录。
3. **验证码登录**：获取短信验证码（需后台开通短信；测试环境可用管理端配置的**模拟验证码**）。
4. **微信登录**：微信内 / 小程序内可用，需管理端配置微信参数；未配置会提示未开通。

### 注册

- 填写手机号、验证码、密码；邀请码**可留空**。
- 须勾选协议。注册成功后可返回「我的」查看个人信息。

### 找回密码 / 修改密码

- 「忘记密码」：手机号 + 验证码重置。
- 登录后在设置里可「修改密码」「换绑手机号」。

## 首页（`pages/index/index`）

打开应用默认进入首页，主要区块：

1. **品牌区**：「租赁商城」、 slogan「品质好物 · 随心所租」。
2. **城市选择**：顶部可选城市（影响部分推荐与活动）。
3. **搜索框**：点击进入搜索页，按关键词找租赁商品。
4. **分类宫格**：手机专区、电脑专区、平板、耳机音箱、电动车等快捷入口。
5. **活动轮播**：运营配置的 Banner。
6. **租机流程**：选商品 → 身份认证 → 缴保证金 → 开始下单（图示说明）。
7. **热租爆品**：按品类 Tab 切换的热租商品列表。

首页接口失败时：界面仍在，但活动图、商品可能为空。

## 分类（`pages/category/index`）

- 左侧 **一级分类** 列表，右侧 **二级分类** 与商品图。
- 顶部搜索「分类名称」。
- 点分类进入 **分类商品列表**（`pages/index/categoryList` 等）。

---

## 商品详情与下单（`subpackage/goods`）

### 商品详情（`goodsDet`）

- 多图轮播、价格、押金说明、规格选择。
- 可选 **租期天数**（来自管理端「租赁天数」配置）。
- 用户评价、商品参数、租赁须知。
- 收藏、分享、联系客服入口。

### 确认订单（`orderDet` 等）

- 收货地址、配送方式（快递 / 自提以页面为准）。
- 费用明细：租金、押金、优惠券抵扣、会员价。
- 提交订单后进入支付（微信 / 支付宝，需已配置）。

---

## 订单（`pages/order/index`）

顶部常见两个维度：

- **快递订单 / 自提订单** 切换。
- 状态 Tab：**全部、待付款、待发货、待收货、待归还、已归还** 等。

### 我的订单快捷入口（在「我的」页）

| 入口 | 含义 |
|---|---|
| 待付款 | 已下单未支付 |
| 待发货 | 已支付，等待发货 |
| 待收货 | 已发货，在途或待确认收货 |
| 待评价 | 已完成待评价 |

点「全部订单」查看完整列表。

### 订单详情（`subpackage/order/orderDet`）

- 订单号、商品信息、租期、租金与押金。
- 按钮因状态变化：去支付、取消、查看物流、确认收货、申请归还、填写归还物流、继续租赁、买断、评价等。

### 物流与售后

- **物流查询**（`pages/order/search` 等）。
- **评价**（`pages/order/feedback`）。
- 订单投诉、联系客服。

---

## 我的（`pages/my/index`）

### 顶部

- 未登录：**点击登录**。
- 已登录：头像、昵称、信誉标签、**实名认证** 状态、消息入口。
- **收藏 / 浏览记录 / 优惠券** 数量摘要。

### VIP 尊享卡

- 未开通显示开通引导；已开通显示权益与续费入口（`my` 子包内 VIP 相关页）。

### 常用服务（常见）

| 名称 | 作用 |
|---|---|
| 实名认证 | 提交身份证件资料 |
| 我的钱包 | 余额、明细、提现 |
| 地址管理 | 收货地址维护 |
| 客服中心 | 联系客服 / 聊天 |
| 意见反馈 | 提交反馈 |
| 关于我们 / 设置中心 | 协议、注销、换绑手机等 |

具体图标是否全部显示，受后台开关与小程序配置影响。

---

## 钱包、邀请、积分

### 钱包（`my/wallet`）

- 余额、**资金明细**、**提现**（填收款账号）、**提现记录**。
- 提现需后台审核，**不会秒到账**。

### 邀请（团队 / 收益相关页）

- 邀请码、海报分享；下级注册 / 消费产生收益（规则以后台为准）。

### 优惠券（`my/ticket` 等）

- 我的优惠券列表与使用记录。

### 收藏与浏览（`my/myCollection`、`my/liulanGoods`）

- 收藏的商品、历史浏览记录。

---

## 消息与客服

- **消息列表**（`pages/msg`）：系统通知、活动消息。
- **在线客服 / 聊天**（`pages/msg/chat`、`my/setting/chat`）：WebSocket 连接，依赖 `config.js` 中的 `WSHOST`、`WSHOST1`。
- 未配置或本地未启 WSS 时，聊天可能连不上，但其它功能不受影响。

---

## 和后台、服务端的关系

1. **所有列表数据**都来自服务端；没起服务或地址配错 → 空白或报错。
2. 管理端改价、下架商品、改轮播 → 用户端需 **下拉刷新或重新进入** 才更新。
3. 支付、短信、地图、微信 → 必须在 **管理端配置列表** 里开通；用户端无法填商户密钥。
4. 连 **线上 H5** 时看到的是 **线上库**；连 **本机 9101** 时看到的是 **你本机导入的数据**，两套互不影响。

---

## 你最常遇到的三种情况

| 现象 | 原因 | 处理 |
|---|---|---|
| 商品列表「暂无数据」 | 本机库无商品，或分类下未上架 | 管理端发布商品并上架；确认已导入 `lease-shop.sql` |
| 支付按钮没反应 | 未配置微信 / 支付宝 | 管理端配置列表填密钥，或用线上演示环境 |
| 验证码收不到 | 未配短信且未开模拟 | 管理端开短信模拟，用固定验证码测试 |

更底层的接口与规则见 [服务端功能说明](服务端-功能说明.md)。
