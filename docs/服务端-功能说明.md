# 服务端功能说明

这份说明用白话写：服务端**没有给用户点的页面**。它是一直在后台运行的 Java 程序（文件夹 **`zulinshangcheng-server`**）。

用户端和管理端把请求发给它，它查数据库、改数据，并在需要时访问短信、微信、支付宝、图床、地图等外部服务。

怎么启动见 [服务端运行教程](服务端-运行教程.md)。

---

## 它放在哪里、怎么访问

| 项目 | 说明 |
|---|---|
| 代码目录 | `zulinshangcheng-server` |
| 启动类 | `com.sqx.SqxAdminApplication`（控制台成功标志：**`租赁商城启动成功`**） |
| 数据库脚本 | `zulinshangcheng-server/sql/lease-shop.sql` |
| 建议数据库名 | `lease-shop`（须与 `application-dev.yml` 中 JDBC 库名一致） |
| 默认端口 | **9101**（见 `application.yml`） |
| 所有接口前缀 | `/sqx_fast` |
| 在线文档 | 浏览器打开 `http://127.0.0.1:9101/sqx_fast/swagger-ui.html`（Swagger） |
| 图片上传 | `POST /sqx_fast/alioss/upload`，表单字段 `file`，**无需登录**（Shiro 已放行） |

数据库里大致包括：管理员与权限、C 端用户、商品分类与 SKU、租赁订单、租期规则、优惠券、会员、钱包与提现、邀请关系、消息与评价、轮播与活动、系统配置等。

## 它为用户端（`zulinshangcheng-uniapp`）做的事

### 注册与登录

- 手机号 + 密码登录；手机号 + 短信验证码登录 / 注册；找回密码。
- 微信相关登录（小程序 / H5 等，需在后台配置 AppId、Secret）。
- 登录成功后下发 **token**（JWT 一类凭证），后续请求在头里带 `token`（以接口文档为准）。

### 首页与逛商品

- 首页轮播、活动入口、分类宫格（手机、电脑、家电等专区）。
- 城市选择与搜索关键词。
- **热租爆品**、人气精选列表。
- 下拉刷新重新拉取活动与推荐。

### 分类与商品

- 左侧一级分类、右侧二级分类与商品图。
- 商品列表：排序、筛选（以页面为准）。
- **商品详情**：多图、规格（SKU）、日租金、租期选项、押金说明、评价。
- 收藏商品、浏览记录。

### 下单与租赁

- 选择规格、租期天数、数量，计算 **租金 + 押金**（规则以后台配置为准）。
- 填写收货地址；支持 **快递发货** 与 **到店自提**（以订单类型为准）。
- 可用优惠券、会员折扣。
- 创建订单后跳转微信 / 支付宝支付（需已配置支付）。

### 订单全流程

常见状态（与代码注释一致，界面文案可能略有不同）：

| 状态码（后台） | 含义（通俗） |
|---|---|
| 0 | 待支付 |
| 1 | 已支付，待发货 |
| 2 | 已发货，待收货 |
| 3 | 已收货（使用中） |
| 4 | 待归还 |
| 5 | 归还中 |
| 6 | 已完成 |
| 7 | 继续租赁 |
| 8 | 买断 |
| 9 | 已取消 |
| 10 | 待评价 |

用户端可操作：支付、取消、确认收货、查看物流、申请归还、填写归还物流、评价、投诉等（以实际页面按钮为准）。

### 会员、优惠券、积分

- **VIP 尊享卡**：套餐价格、权益说明、开通与续费（走支付通道）。
- 优惠券列表、领取、下单抵扣。
- 积分账户、积分商城兑换、积分明细。

### 钱包与邀请

- 钱包余额、资金明细。
- 提现申请（写入待审核，**不自动打款**）。
- 邀请码、邀请好友、团队与分销收益（以配置为准）。

### 其他

- 收货地址管理。
- **实名认证**资料提交与状态查询。
- 开具发票、开票记录。
- 站内消息、在线客服、**WebSocket** 聊天（地址在用户端 `common/config.js` 的 `WSHOST` / `WSHOST1`）。
- 帮助中心、用户协议、隐私政策等文案（后台配置）。
- **文件上传**：头像、评价图、聊天图片等，走 `/alioss/upload`，返回可访问的 `https` 地址。

## 它为管理端（`zulinshangcheng-admin`）做的事

- 管理员登录：用户名 + 密码 + **图片验证码**（路径形如 `/sqx_fast/captcha/captcha.jpg`）。
- **首页 / 数据中心**：用户数、订单、收入等统计（以页面为准）。
- **用户列表**：查询 C 端用户、详情、禁用等。
- **商品管理**：分类、品牌、标签、发布商品、规格 SKU、上下架、评论管理。
- **租赁配置**：租赁须知、租期天数、商品配件、赠品配件等。
- **订单中心**：全平台订单查询、改状态、发货、售后处理。
- **营销**：优惠券、秒杀、拼团、积分商品、抽奖等（菜单是否显示取决于角色权限）。
- **财务中心**：提现审核、支付流水统计。
- **消息中心、聊天室、评价管理**。
- **实名认证**审核。
- **配置列表 / 商城配置**：微信、支付宝、短信、OSS、开关与协议文案。
- **系统管理**：管理员、角色、菜单（谁能看到哪个按钮）。

具体菜单名称以你登录后左侧实际显示为准（与角色权限绑定）。

## 业务规则（通俗说明）

### 租赁下单

1. 用户在商品详情选好规格和租期，进入确认页，填写地址。
2. 服务端校验库存、租期规则，生成订单与应付金额（含押金说明）。
3. 用户支付成功（微信 / 支付宝回调）后，订单进入「待发货」等后续状态。
4. **未配置支付**时，可走完界面，但无法真实扣款，状态可能停在待付款。

### 收货、使用与归还

1. 商家或平台在管理端 **发货**，用户端可 **查物流、确认收货**。
2. 租期临近结束，订单进入 **待归还**；用户寄回设备并填写物流，状态为 **归还中**。
3. 平台确认收回后订单 **已完成**，押金按规则退还（具体以运营流程为准）。

### 继续租赁与买断

1. 租期结束前，用户可选择 **继续租赁**（延长租期并支付相应费用）。
2. 用户也可选择 **买断** 商品（支付买断价，订单状态变为买断）。

### 会员与优惠券

1. 会员套餐价格、权益在管理端配置；用户购买后服务端写会员到期时间。
2. 优惠券有发行量、门槛、有效期；下单时服务端计算是否可用。

### 提现

1. 用户发起提现，只在库里记「待审核」。
2. 管理端财务审核通过后，**系统不会自动转账**，需人工按用户填写的收款账号打款。

### 邀请推广

1. 注册时可填邀请码，与邀请人绑定。
2. 下级消费产生收益时，按后台比例记入邀请人钱包（以配置为准）。

## 对接了哪些外面的服务

下面每一项都需要在**管理端配置**或环境变量里填密钥。没填时，对应功能会报错或提示未开通。

| 能力 | 用途 | 常见申请入口 |
|---|---|---|
| 短信 | 验证码注册 / 登录 | 阿里云短信、腾讯云短信等 |
| 微信 | 登录、支付、模板消息 | 微信公众平台、微信支付商户 |
| 支付宝 | 支付 | 支付宝开放平台 |
| 对象存储 | 商品图、聊天图 | 阿里云 OSS 等（也可本机磁盘上传联调） |
| 物流查询 | 快递轨迹 | 快递鸟等（若已对接） |

### 仅操作本库、不依赖外网也能试的功能

（前提是：**MySQL 已导入数据且服务端已启动**）

- 管理端登录（验证码图片由本机服务端生成）。
- 浏览已配置的商品、分类、轮播（库里已有数据时）。
- 用户端看首页布局、点菜单（列表取决于接口是否返回数据）。
- `POST /sqx_fast/alioss/upload` 上传图片（走当前环境配置的存储）。

## 两个前台怎样配合

1. **先服务端，再管理端，再用户端**；三个窗口都需保持运行（服务端尤其不能关）。
2. 管理端改完价格、下架商品、改轮播后，手机端要**刷新或重新进入页面**才会看到新数据。
3. 用户端 `common/config.js`、管理端开发代理（`config/index.js` 的 `proxyTable`）里的地址必须指向**你正在跑的那台服务端**。
4. 线上演示站（如 `leaseshopyh.xianmxkj.com`）连的是线上库；你本机管理端改的数据，不会自动出现在线上用户端。

页面级说明见 [管理端功能说明](管理端-功能说明.md)、[用户端功能说明](用户端-功能说明.md)。
